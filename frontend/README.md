# Campus Customs Agent Desk (frontend)

React + Vite + TypeScript board for the hw5 agent team. See the top-level `README.md` for the full setup.

```bash
npm install
npm run dev      # http://localhost:5177, talks to the backend at http://localhost:8017
```

Change the backend URL by copying `.env.example` to `.env` and editing `VITE_API_BASE`.
Design notes: `../output/design.md`.
